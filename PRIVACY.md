# Privacy policy for Wordle Archive Navigation

Last updated: September 21, 2026

Wordle Archive Navigation does not collect, store, sell, share, or transmit personal information or user data.

The extension runs only on New York Times Wordle pages. It processes the current page address locally to determine the puzzle date and add links to the previous and next puzzles. This information never leaves the user's browser.

The extension does not use analytics, advertising, cookies, external services, or remote code.

Any information handled by the extension is used only to provide its visible archive navigation feature. This use follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

Questions about this policy can be submitted through the extension's support page.
